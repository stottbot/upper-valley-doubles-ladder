Report a result

The winning team emails uppervalleytennisladder@gmail.com within 24 hours, cc'ing the other team. One line is enough:

Result: Federer/Nadal d. Borg/McEnroe 6-3 4-6 [10-7]

Include the date if it wasn't today. Last names are enough (the site shows first name + initial, but report with last names). Say "forfeit" if it was one, and "free challenge" if you used yours. The standings update overnight; anything the parser can't read goes to the commissioner.
